# lowHD / QoL 및 D2R Multigate Launcher 한국어 안내

**제작: celloboy126**  
[lowHD / QoL 모드 다운로드](https://github.com/celloboy126/lowHD/releases/latest) · [Multigate Launcher 다운로드](https://github.com/celloboy126/D2R-Multigate-Launcher/releases/latest)

## 어떤 모드를 쓰면 되나요?

| 모드 | 용도 |
| --- | --- |
| **lowHDpartial** | 지형과 주요 게임 화면을 더 많이 남긴 경량 모드입니다. 화면을 보며 직접 플레이할 계정에 적합합니다. |
| **lowHDmain** | 배경과 이펙트를 더 적극적으로 줄여 성능을 우선합니다. 지형이나 배경의 일부가 검게 보일 수 있습니다. |
| **lowHDfiller / lowHDmin** | 방 인원을 채우는 보조 계정용입니다. min은 화면 표시를 가장 많이 줄입니다. |
| **QoL** | 원본 그래픽에 가까운 상태에서 패널, 대기실, 단축키 관련 편의 기능을 사용하려는 분께 적합합니다. |

## 설치와 그래픽 설정

1. 실행 중인 디아블로 II: 레저렉션을 종료합니다. 런처의 **lowHD / QoL 모드** 메뉴에서 설치하거나, GitHub 릴리스의 **Assets**에서 원하는 ZIP을 받아 게임의 `mods` 폴더에 풉니다. 예: `mods/lowHDpartial/lowHDpartial.mpq/modinfo.json`.
2. 계정의 실행 인수에 `-mod lowHDpartial`을 지정합니다. 다른 모드라면 이름을 바꿉니다. main과 partial은 `-txt`로 투사체 이펙트를 추가로 줄일 수 있습니다. 소리가 필요 없는 보조 계정에는 `-ns`를 추가할 수 있습니다.
3. lowHD는 **가장 낮은 그래픽 프리셋**을 권장합니다. ZIP의 `optimal_settings`에 있는 설정을 사용하거나 게임 안에서 직접 낮추세요. 설정 파일을 복사할 때는 기존 파일을 먼저 백업하고 해당 계정이 실제로 사용하는 저장 폴더에 적용하세요.
4. partial은 런처에서 **추출된 게임 데이터 복사**를 선택해 빠진 리소스를 추가할 수 있습니다. 디스크 공간이 더 필요합니다. 이 작업은 partial 전용이며, 모드로 실행할 때 `-direct`는 필요하지 않습니다. 새 partial에는 인트로와 액트 영상 및 전용 음원 16개가 0바이트 파일로 들어 있어, 복사 시 원본 약 2.15 GiB가 중복으로 들어가지 않습니다.

## 화면이 검게 나오거나 배지가 어긋날 때

- partial에서 HUD만 보이고 배경이 거의 검다면 가장 낮은 그래픽 프리셋을 적용하고 게임을 완전히 재시작하세요. 이미 낮음이라면 다른 프리셋을 한 번 적용한 뒤 다시 가장 낮은 설정으로 바꿔 보세요.
- lowHD의 `data/hd/shaders`에는 일부 렌더링을 줄이기 위해 수정한 셰이더가 포함되어 있습니다. 파일을 0바이트로 비우는 방식은 해당 리소스를 그대로 읽는 게임 경로에 영향을 줄 수 있으며, 검은 화면이나 누락된 효과를 일으킬 수 있습니다. 임의로 셰이더를 더 지우기보다는, 최저 설정으로 먼저 확인하고 원본 그래픽이 필요하면 QoL을 사용하세요. partial의 이번 0바이트 변경은 영상과 전용 음원에만 적용됩니다.
- 금색 HUD 배지와 그 위의 직사각형은 런처가 화면 상태와 인원을 읽는 데 쓰입니다. 위치가 어긋나거나 방 입장이 감지되지 않으면 게임 창 전체가 보이는 스크린샷과 해상도, 창 모드, 모드 이름, 런처 버전을 함께 알려 주세요. 하단 HUD와 양쪽 인원 표시가 보이면 확인에 도움이 됩니다.
- 이번 partial에서 인트로 또는 액트 전환이 멈춘다면 재현된 지점을 알려 주세요. 영상 복구가 필요하면 정확히 같은 경로에 추출한 원본 영상과 음원을 복사해 해당 빈 파일만 덮어쓸 수 있습니다.

## 런처 빠른 시작

- **설치:** 릴리스의 `Setup.exe`를 실행하거나 `Portable.zip`을 풉니다. 런처 하단에서 **한국어**를 선택하세요. 계정별 실행, 일괄 실행, 입력 브로드캐스트, 방 만들기/참가, BO(전투 지시) 지원, 자동 주차 등을 설정할 수 있습니다.
- **일반 방 만들기/참가:** `Ctrl+Space`는 다음 방을 만들거나 참가하고, `Ctrl+J`는 활성 계정의 방으로 보조 계정을 참가시킵니다. 따라가기를 켜면 다음 방에 보조 계정이 함께 이동합니다. **설정 → 방 만들기 / 참가**에서 게임을 찾을 수 없다는 오류에 대한 재시도 간격과 최대 횟수를 조절할 수 있습니다. 기본값은 1초 간격, 최대 2회이며 0이면 재시도를 끕니다.
- **온라인 · 안정 모드 (패널):** 모든 참여 캐릭터를 온라인 방에 먼저 넣고 패널을 닫으세요. 설정에서 게임 내 파티/도움말 단축키를 맞춥니다(기본 `P`/`H`). 처음 `Ctrl+Space`를 누르면 방 이름과 비밀번호를 입력합니다. 이후 방 번호는 자동으로 증가하며 `Ctrl+Shift+Space`로 초기화할 수 있습니다. 이 방식은 입장 성공을 화면에서 확인하지 않으므로 썸네일이나 방 인원수로 확인해 주세요.
- **오류 제보:** 언어 선택 옆 **진단 및 피드백**을 열고 실행한 단축키, 계정 수, 멈춘 화면을 적어 주세요. 계정 이름이나 비밀번호는 직접 입력할 필요가 없습니다. 스크린샷을 첨부할 경우 개인정보나 방 비밀번호가 보이지 않는지 먼저 확인하세요.

기존 모드를 직접 수정했다면 업데이트 전에 폴더를 백업하거나 다른 이름으로 보관하세요. 런처의 번들 모드 자동 교체는 설치된 모드 폴더와 그 안에 복사한 추출 데이터를 새 패키지로 교체할 수 있습니다.
